РАБОТА 3.3.4. ЭФФЕКТ ХОЛЛА В ПОЛУПРОВОДНИКАХ — результаты обработки
Файл создан скриптом hall_334.py. Обозначения: I — ток через образец, I_M — ток электромагнита,
U_perp — ЭДС Холла, k = dU_perp/dB, R_H — постоянная Холла, n — концентрация, mu — подвижность.
Запись «(a ± b)·10^p» — погрешность b соответствует доверительной вероятности ~68 % (1 сигма).
Числа в «ИТОГОВЫХ РЕЗУЛЬТАТАХ» округлены по правилам пособия, в остальных разделах — без округления.

0. ЧТО ПРОВЕРИТЬ ПЕРЕД ВСТАВКОЙ В ОТЧЁТ (допущения)
==============================================================================
* Толщина образца h = 1.7 мм взята из параметра 'l' листа parameters (в методичке l — это расстояние 3–5,
  в xlsx оно называется L_35 = 3 мм). Если h на держателе другая — поправь H_MM_OVERRIDE.
* Приборные погрешности — допущения по правилу пособия (макс. погрешность ~ цене деления / последнему разряду):
  U34, U0: ±1 мкВ каждое; U35: ±0.001 мВ; миллиамперметр образца: ±1 дел = ±0.01 мА;
  a, h, l35: ±0.1 мм (по умолчанию ±1 в последней значащей цифре); прибор для градуировки B: ±1 %.
  Паспортных классов точности в данных нет — при необходимости заменить в блоке НАСТРОЙКИ.
* Знак носителей зависит от двух флагов, которых нет в данных: B_FWD_TOWARD_VIEWER=True, U34_IS_PHI3_MINUS_PHI4=True.

3. ЭДС ХОЛЛА: U_perp = U34 - U0 (ф. (1)), ЛИНЕЙНЫЕ АППРОКСИМАЦИИ U_perp = k·B + b   [fig2_hall_family_Uperp_of_B.pdf]

Среднее χ²/dof по сериям = 0.58.  Критерий пособия: ~1 — модель и погрешности согласованы; <0.5 — погрешности завышены;
  >1.5 — плохое согласие или заниженные погрешности. Критерий «≈2/3 крестов пересечено» — для проверки линейности по графику.
Линейность U_perp(B): у серий I = 1.00, 1.30 мА прямая пересекает менее 2/3 крестов (малые отклонения от линейности/шум, χ²/dof близко к 1 — в пределах погрешностей), у остальных — не менее 2/3.

  На наклон k остаточное поле не влияет, поэтому аппроксимация с отрезком (двухпараметрическая) корректна.

4. ЗАВИСИМОСТЬ k(I) И ПОСТОЯННАЯ ХОЛЛА R_H   [fig4_k_of_I.pdf]

Теория (ф. (3.27)): U_perp = R_H·I·B / h  =>  k = (R_H / h)·I  — прямая через ноль с наклоном s = dk/dI = R_H / h.
Погрешность по оси I (±0.01 мА) учтена эффективной дисперсией σ_k² + (s·σ_I)².
Аппроксимация k = s·I + k0:  s = 0.44243 ± 0.00465 мкВ/(мТл·мА)  [= В/(Тл·А)],  k0 = -0.00052 ± 0.00348 мкВ/мТл,
   χ²/dof = 0.06;  k0 отличается от нуля на 0.2 σ.
Аппроксимация через ноль:      s = 0.44184 ± 0.00240  мкВ/(мТл·мА),  χ²/dof = 0.05
   (разница наклонов двух вариантов: 0.1 σ двухпараметрической).
Для итога используется двухпараметрический вариант (пособие, п. 4.1.1).
χ²/dof = 0.06 << 1: точки лежат на прямой заметно лучше, чем допускают погрешности — они (в основном σ_I = 1 дел) заведомо завышены, оценка погрешности наклона консервативна.

Наклон, поле обращено (U34 - U0_обр):   k = 0.58887 ± 0.00178 мкВ/мТл   (B взято со знаком «−»)
Метод полуразности U_perp = [U34(+) - U34(−)]/2, точки I_M = 0…: k = 0.57832 ± 0.00114 мкВ/мТл,  b = -3.31 ± 0.54 мкВ
Расхождение наклонов вперёд/назад: 6.0 σ; вперёд/полуразность: 2.1 σ.
Метод полуразности не использует U0: омическая добавка от несоосности контактов 3, 4 одинакова при обоих направлениях поля и вычитается.
Контроль R_H по одной серии (I = 1.30 мА, полуразность): R_H = k·h/I = 756 ± 45 см³/Кл (без калибровочных и приборных поправок), основной результат (раздел 7) — 752 см³/Кл.
Знак U_perp меняется на обратный при обращении поля — это эффект Холла (омическая добавка от несимметрии контактов от поля не зависит).
Для метода полуразности отрезок b = -3.31 ± 0.54 мкВ не равен нулю: B(I_M) при обращении поля не строго симметрична (гистерезис,
остаточное поле); на наклон это влияет слабо.
Наклоны вперёд и назад различаются на 2.6 % — это существенно больше статистической погрешности (0.31 %).
Половина этой разности (1.3 %) добавлена в бюджет погрешностей как систематика от направления поля/гистерезиса (раздел 8).

6. ЗНАК НОСИТЕЛЕЙ (п. 9)
==============================================================================
Геометрия рис. 1б: ток от контакта 2 (+) к контакту 1 (−) («вверх»), контакт 3 слева, 4 справа. При B на наблюдателя
носители обоих знаков отклоняются к контакту 4: электроны -> U34 = φ3-φ4 > 0, дырки -> U34 < 0.

ВЫВОД (при этих допущениях): основные носители — электроны (n-тип).
Независимая проверка: подвижность |mu| сравнивается со справочной для электронов и дырок в Ge (раздел 9) —
значение mu заметно выше справочной подвижности дырок в Ge (1900 см²/(В·с)) — дырочная проводимость маловероятна.

9. СРАВНЕНИЕ С ТАБЛИЧНЫМИ ЗНАЧЕНИЯМИ (п. 17)
==============================================================================
Справочные подвижности Ge при 300 К (проверь по таблицам из задачника): электроны (n-Ge, 300 К) 3900; дырки (p-Ge, 300 К) 1900 см²/(В·с).
  mu_эксп = 5156 ± 399  против электроны (n-Ge, 300 К): 3900  ->  разность +1256 (+3.1 σ, +32 %)
  mu_эксп = 5156 ± 399  против дырки (p-Ge, 300 К): 1900  ->  разность +3256 (+8.2 σ, +171 %)
Концентрация n и удельное сопротивление зависят от степени легирования конкретного образца; универсальных табличных значений нет —
сравнивать можно с данными, указанными на держателе/в описании установки. Холл-фактор принят равным 1 (R_H = 1/(n e)).
Расхождение со справочной подвижностью для найденного типа носителей значимо (> 2σ). Возможные причины: систематика размеров образца
(mu ∝ l35/a — ошибка a или l35 прямо входит в результат), приборные классы точности, холл-фактор r_H ≠ 1, температура, примеси,
а также нелинейность/гистерезис калибровки. Какая именно — по этим данным установить нельзя.
